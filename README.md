# Diabetic-Retinopathy-Detection
Diabetic Retinopathy Detection is an AI-based system that classifies retinal images into DR severity levels using EfficientNet, Vision Transformers and XAI techniques (Grad-CAM, SHAP, LIME) for interpretability. It also integrates LLMs for test/treatment recommendations. Built with TensorFlow/Keras, it enhances early diagnosis and decision-making.
